МОИ ФИНАНСЫ — файлы приложения

index.html            — само приложение
config.js             — настройки (данные Firebase, имя и почта)
manifest.webmanifest  — чтобы приложение ставилось на телефон с иконкой
sw.js                 — чтобы открывалось быстро и без интернета
icons/                — иконки
firestore-rules.txt   — правила доступа к базе (вставляются в Firebase)

Это отдельное приложение со своей базой. С «Нашими тратами» и «Лимитами» не связано.
